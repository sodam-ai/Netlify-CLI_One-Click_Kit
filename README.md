# Netlify 원클릭 키트 (Netlify CLI One-Click Kit)

**내가 만든 웹사이트를 인터넷에 공개**해 주는 도구(Netlify CLI)를, **명령어를 몰라도** 클릭 몇 번으로
**설치 · 사용 · 제거**할 수 있게 만든 **왕초보용** 키트입니다. 한국어 안내판이 **"지금 누를 번호"** 를 알려줍니다.

> 영어 안내가 필요하면 [README.en.md](./README.en.md) 를 보세요. (English version available)
> 그림처럼 따라 하는 자세한 설명서: [사용설명서.md](./사용설명서.md)

## 1. 이게 뭔가요? (1분 이해)

- **Netlify(넷리파이)** 는 내가 만든 웹사이트를 인터넷에 올려 **주소(URL)** 를 받게 해 주는 서비스입니다.
- 원래는 검은 창에 **영어 명령어**를 직접 입력해야 했습니다. 처음 다루는 사람에겐 큰 벽입니다.
- 이 키트는 그 과정을 **한국어 메뉴 + 번호 선택**으로 바꿨습니다. **외울 명령어가 없습니다.**

---

## 2. 먼저 알아둘 단어 5개

| 단어 | 쉬운 뜻 |
|---|---|
| **Node.js (노드)** | 자동차의 **엔진** 같은 받침 프로그램. Netlify 도구가 돌아가려면 꼭 필요. **한 번만** 설치. |
| **검은 창 (콘솔/터미널)** | 컴퓨터에 글자로 일을 시키는 창. 키트가 **자동으로 열었다 닫음**. 정상입니다. |
| **Netlify 계정** | 넷리파이에 들어가는 **내 아이디**. 없으면 **무료 가입**(카드 필요 없음). |
| **배포 (Deploy)** | 내 웹사이트를 인터넷에 **올려 공개**하는 일. **미리보기**(나만)와 **진짜 공개**(누구나) 두 가지. |
| **CLI** | "명령으로 쓰는 도구". 우리는 **메뉴만 누르니** 명령어를 외울 필요 없음. |

## 3. 사전 준비물 · 필요 프로그램

### 꼭 필요한 것
- **윈도우 10 또는 11** (이 키트는 윈도우 전용)
- **인터넷 연결** (설치·로그인·배포에 필요)
- **Node.js v20.12.2 이상** (LTS 버전) — 이 키트가 자동으로 깔아주지 **않습니다**. 직접 설치해야 합니다. (방법은 6번)
- **Netlify 계정** (무료) — 로그인 단계에서 필요. 없으면 https://app.netlify.com 에서 가입.

### 이 키트가 대신 설치해 주는 것
- **netlify-cli** — Netlify 도구 본체. `INSTALL.bat`(또는 메뉴 [1] 설치하기)가 자동으로 깝니다.

> 정리: **사람이 직접 준비** = Windows + 인터넷 + Node.js + Netlify 계정. **키트가 처리** = netlify-cli 설치.

## 4. 빠른 시작 (3분)

1. 폴더 안의 **`시작하기.bat`** 를 **더블클릭**.
2. 화면 아래 **`>> 지금 할 일`** 한 줄을 그대로 따라가기.
3. **[1] 설치하기** → (끝나면) **[2] 사용하기 → [1] 로그인** → **[4] 연습용 사이트로 배포 체험**.
4. 임시 주소가 나오면 눌러서 **"축하합니다!"** 화면이 보이면 성공입니다.

> **고르는 법:** 위/아래 화살표 + Enter, 또는 번호키. **그냥 Enter** 면 초록색 **추천** 항목 실행. **ESC** = 취소/뒤로.
> 화면 아래 **"지금 고른 항목: …"** 설명으로 누르기 전에 무엇을 고르는지 확인할 수 있습니다.

## 5. 다운로드 · 차단 해제

인터넷에서 받은 파일(zip)은 윈도우가 안전을 위해 **잠가둘 때**가 있습니다. 풀어주면 됩니다.

1. (가장 쉬움) 압축 풀기 **전에**, 받은 zip 파일 **우클릭 → 속성 → 맨 아래 '차단 해제(Unblock)' 체크 → 확인** → 그다음 압축 풀기.
2. 파란 **"Windows의 PC 보호"** 창이 뜨면 → **추가 정보 → 실행**.

> `시작하기.bat`가 한 번 실행되면 폴더 안 나머지 파일 잠금은 **자동으로 풀립니다.** (보통 처음 한 번만 신경 쓰면 됩니다.)

## 6. 설치 방법

1. `시작하기.bat` → **[1] 설치하기**.
2. **관리자 허용 창은 뜨지 않습니다.** (Netlify는 내 사용자 폴더 `%APPDATA%\npm` 에만 설치돼 관리자 권한이 필요 없음.)
3. 검은 창이 영어로 6단계 진행됩니다. **닫지 말고 기다리세요(3~10분).**
   글자가 한참 **멈춰 보여도 정상**입니다(파일 받는 중). 창을 닫으면 설치가 깨집니다.
4. `ALL DONE!  NETLIFY CLI IS INSTALLED.` 가 보이면 성공.

**Node.js가 없다고 나오면** → https://nodejs.org 에서 **LTS(숫자 20 이상)** 를 받아 설치한 뒤, 창을 닫고 `시작하기.bat`를 다시 실행 → [1].

자세한 그림 설명·오류표는 [사용설명서.md](./사용설명서.md) 참고.

## 7. 실행 · 사용 · 작동 방법

`시작하기.bat` 를 더블클릭하면 **내 컴퓨터 상태**(Node·CLI·로그인)를 자동으로 보고, **지금 할 일**을 한 줄로 안내합니다.

**시작 메뉴 (한국어)**

| 번호 | 항목 | 하는 일 |
|---|---|---|
| 1 | 설치하기 | Netlify 도구를 컴퓨터에 설치 |
| 2 | 사용하기 | 로그인 / 연습 배포 / 내 사이트 배포 (한국어 서브메뉴) |
| 3 | 문제가 생겼어요? | **자가 진단** — 무엇이 문제인지 점검하고 한국어 해결법 표시 (안전) |
| 4 | 제거하기 | Netlify 도구만 깨끗이 제거 (내 코드는 안 지움) |
| 5 | 사용설명서 | 왕초보 가이드 문서 열기 |
| 6 | Netlify 대시보드 | 브라우저에서 내 사이트 관리 페이지 열기 |
| 0 | 끝내기 | 안내판 닫기 |

**[2] 사용하기 서브메뉴**: 1 로그인 · 2 로그인 상태 확인 · 3 내 사이트 목록 · **4 연습용 사이트로 배포 체험(추천)** · 5 인터넷에 올리기(내 폴더 배포) · 6 전체 메뉴(영어 26가지) · 0 뒤로.

**작동 원리(간단):** 한국어 안내판(`lib\start.ps1`)이 영어 엔진(`INSTALL/RUN/UNINSTALL.bat`)을 대신 호출하고, 상태를 매번 다시 읽어 안내합니다.

## 8. 전체 워크플로우 (흐름)

```
시작하기.bat 더블클릭
        │
        ▼
 [1] 설치하기  ──(Node 없으면 nodejs.org에서 설치 후 다시)──┐
        │                                                  │
        ▼                                                  │
 [2] 사용하기 → [1] 로그인 (없으면 무료 가입 먼저) ◄────────┘
        │
        ▼
 [2] 사용하기 → [4] 연습용 사이트로 배포 체험  (성공 한 바퀴 경험)
        │
        ▼
 내 웹사이트 준비 → [5] 인터넷에 올리기
        │
        ├─ [1] 미리보기 (안전, 임시 주소)   ← 항상 먼저
        └─ [2] 진짜 공개 (YES 입력)         ← 확실할 때만
```

## 9. 제거(삭제) 방법

1. `시작하기.bat` → **[4] 제거하기**.
2. **[1] 미리보기**로 무엇이 지워지는지 먼저 확인 → **[2]** 에서 **`YES`(대문자)** 입력.

**제거해도 그대로 두는 것:** 내 **웹사이트 코드 파일**, **Node.js**, Netlify 서버에 올라간 **내 사이트**. (Netlify 도구·로그인 키·캐시만 지웁니다.)

## 10. 문제 · 오류 대처

> **무엇이 문제인지 모르겠다면** `시작하기.bat` → **[3] 문제가 생겼어요?(자가 진단)**.
> Node·설치·로그인·인터넷을 점검해 **한국어 해결법**을 바로 알려줍니다.

| 증상 | 해결 |
|---|---|
| `NETLIFY CLI IS NOT INSTALLED` | [1] 설치하기 먼저 |
| 설치했는데 `netlify ... not found` | 창을 모두 닫고 **새 창**에서 다시 `시작하기.bat` |
| `Node.js is NOT on this computer` | https://nodejs.org 에서 **LTS** 설치 후 다시 [1] |
| `The install did not finish` | 인터넷/백신/회사망 확인 → 백신 10분 끄고 다시. (자세한 단계는 사용설명서) |
| 파일이 안 열림 / "PC 보호" 경고 | 5번 "다운로드 차단 해제" |

가장 흔한 원인은 **인터넷 차단(회사·학교망)** 과 **백신**입니다. 자세한 단계별 복구는 [사용설명서.md](./사용설명서.md) 의 "오류가 났을 때" 참고.

## 12. 명령어 참고 (선택)

명령어를 몰라도 됩니다. 단, 궁금한 분을 위해 **메뉴가 실제로 실행하는 명령**을 적어둡니다.
영어 전체 메뉴(`RUN.bat`, [2]사용하기 → [6])의 주요 항목:

| 전체메뉴 번호 | 실행 명령 | 뜻 |
|---|---|---|
| 4 / 5 | `netlify login` / `netlify logout` | 로그인 / 로그아웃 |
| 6 | `netlify status` | 로그인·연결 상태 |
| 8 | `netlify sites:list` | 내 사이트 목록 |
| 9 | `netlify init` | 이 폴더를 새 사이트로 시작 |
| 10 / 11 | `netlify link` / `netlify unlink` | 폴더↔사이트 연결/해제 |
| 13 | `netlify dev` | 내 컴퓨터에서 미리보기 서버 |
| 17 | `netlify deploy` | **미리보기** 배포 (안전) |
| 18 | `netlify deploy --prod` | **진짜 공개** 배포 (YES 필요) |
| 20~22 | `netlify env:list/set/unset` | 환경변수 보기/설정/삭제 |
| 23 / 24 | `netlify open:site` / `open:admin` | 내 사이트 / 관리 페이지 열기 |

> 전체 메뉴의 **26번**에서 `netlify` 뒤에 원하는 명령을 직접 입력할 수도 있습니다(고급).
