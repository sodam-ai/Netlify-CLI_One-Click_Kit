# Netlify CLI One-Click Kit 🚀

> Windows에서 Netlify CLI를 클릭 한 번으로 설치·사용·삭제하는 배치 스크립트 키트

**영어 문서:** [README.en.md](./README.en.md)

---

## 이게 뭔가요?

Netlify는 무료로 웹사이트를 인터넷에 올릴 수 있는 서비스입니다.  
Netlify CLI는 그 서비스를 내 컴퓨터 명령창에서 바로 쓸 수 있게 해주는 도구입니다.

이 키트는 그 도구를 **더블클릭 한 번**으로 설치·사용·삭제할 수 있도록 만든 Windows 전용 스크립트 모음입니다.  
명령창을 몰라도 괜찮습니다. 메뉴에서 번호만 고르면 됩니다.

---

## 파일 구성

```
Netlify-CLI_One-Click_Kit/
├── INSTALL.bat      ← Netlify CLI 설치 (처음 한 번만 실행)
├── RUN.bat          ← 메뉴로 Netlify CLI 사용 (매일 여기서 시작)
├── UNINSTALL.bat    ← Netlify CLI 제거 (더 이상 안 쓸 때)
├── README.md        ← 한국어 가이드 (지금 읽는 파일)
└── README.en.md     ← English guide
```

## 시스템 요구사항

| 항목 | 최소 요구사항 |
|------|-------------|
| 운영체제 | Windows 10 또는 Windows 11 |
| Node.js | **v20.12.2 이상** (LTS 권장) |
| npm | Node.js 설치 시 함께 포함 |
| 인터넷 | 설치 시 필요 (이후 일부 기능만) |

> **Node.js가 없나요?**  
> → [https://nodejs.org](https://nodejs.org) 에서 **LTS** 버전을 다운받아 설치하세요.  
> → 설치할 때 기본값 그대로 "다음"만 누르면 됩니다.

## 왕초보 시작 가이드 (처음이라면 여기부터!)

### 1단계: 설치하기

1. 이 폴더에서 **`INSTALL.bat`** 을 더블클릭합니다.
2. Windows가 "이 앱이 변경하도록 허용하시겠습니까?" 라고 물으면 **"예"** 를 클릭합니다.
3. 검은 창이 열리고 설치가 시작됩니다. **창을 닫지 마세요.**
4. `ALL DONE! NETLIFY CLI IS INSTALLED.` 문구가 나오면 설치 완료입니다.
5. 아무 키나 누르면 창이 닫힙니다.

> ⏱ 설치는 인터넷 속도에 따라 3~10분 걸릴 수 있습니다.

### 2단계: 사용하기

1. **`RUN.bat`** 을 더블클릭합니다.
2. 메뉴가 열립니다. 번호를 입력하고 Enter를 누릅니다.
3. 처음이라면 **`4` (Log in to Netlify)** 를 선택해서 로그인하세요.
4. 브라우저가 열리면 Netlify 계정으로 로그인합니다.
5. 로그인 후 다시 메뉴로 돌아오면 사용할 준비가 된 것입니다.

### 3단계: 웹사이트 배포하기

1. `RUN.bat` 메뉴에서 **`17` (Deploy PREVIEW)** 로 먼저 테스트합니다.
2. 테스트 배포 URL이 나오면 확인합니다.
3. 실제 공개 배포는 **`18` (Deploy to PRODUCTION)** 을 사용합니다.
4. `YES` 를 입력하면 내 웹사이트가 인터넷에 공개됩니다.

## 환경 변수 안내

환경 변수(ENV VAR)는 API 키나 비밀 설정을 코드에 직접 쓰지 않고 안전하게 관리하는 방법입니다.

- **설정 방법:** 메뉴 `21` → 이름 입력 → 값 입력
- **예시 이름:** `API_KEY`, `DATABASE_URL`, `SECRET_TOKEN`
- **주의:** 값을 입력할 때 다른 사람이 보지 않도록 주의하세요.

> ⚠️ API 키나 비밀번호를 `.bat` 파일이나 코드에 직접 적지 마세요.  
> 항상 환경 변수(메뉴 21)로 관리하세요.

## 제거 방법

Netlify CLI가 더 이상 필요 없을 때:

1. **`UNINSTALL.bat`** 을 더블클릭합니다.
2. Windows가 권한을 요청하면 **"예"** 를 클릭합니다.
3. 메뉴에서 `1` 을 눌러 무엇이 제거될지 미리 확인합니다.
4. 제거하려면 `2` → `YES` 를 입력합니다.
5. `ALL DONE! NETLIFY CLI WAS REMOVED.` 가 나오면 완료입니다.

> 웹사이트 파일, Node.js, npm은 제거되지 않습니다. Netlify CLI만 제거됩니다.

## 자주 발생하는 오류와 해결 방법

### "Node.js is NOT on this computer"
→ [https://nodejs.org](https://nodejs.org) 에서 Node.js LTS 버전을 설치하세요.

### "Your Node.js is TOO OLD"
→ 같은 사이트에서 최신 LTS 버전을 재설치하세요. (기존 버전을 덮어씁니다)

### "The install did not finish (tried twice)"
→ 바이러스 백신을 일시 중지하고 다시 시도하세요.  
→ 관리자 권한 명령창에서 `npm install -g netlify-cli --force` 를 실행하세요.

### "Netlify CLI is not on this computer"
→ `RUN.bat` 전에 `INSTALL.bat` 을 먼저 실행하세요.

### "netlify command not found" (설치 후)
→ 창을 닫고 새 창을 열거나 PC를 재시작하세요.

### 방화벽/회사 네트워크에서 설치 실패
→ IT 담당자에게 `registry.npmjs.org` 접근 허용을 요청하세요.

## 보안 주의사항

- API 키, 비밀번호, 토큰을 `.bat` 파일에 직접 입력하지 마세요.
- 다른 사람이 만든 `.bat` 파일은 내용을 확인한 후 실행하세요.
- UNINSTALL.bat 실행 시 Netlify 로그인 정보(토큰)가 삭제됩니다. 필요하다면 재로그인이 필요합니다.
- `netlify deploy --prod` (메뉴 18)는 즉시 공개 배포됩니다. `YES` 입력 전에 반드시 확인하세요.
